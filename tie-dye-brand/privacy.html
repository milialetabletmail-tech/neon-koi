Политика конфиденциальности

Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки персональных данных пользователей сайта LN-Team (далее — «Сайт») в соответствии с требованиями Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных».

Используя форму обратной связи на Сайте, пользователь выражает согласие с условиями настоящей Политики.

1. Оператор персональных данных

Обработку персональных данных осуществляет:

НЕМЧАНИНОВ ПЛАТОН ПАВЛОВИЧ, физическое лицо, применяющее специальный налоговый режим «Налог на профессиональный доход» (самозанятый), ИНН 543600146895.

2. Цель обработки данных

Персональные данные собираются исключительно с целью обратной связи с пользователем — для ответа на вопросы, заданные через форму «На связи».

Иные цели обработки (маркетинг, рассылки, аналитика, профилирование и т. п.) отсутствуют.

3. Состав собираемых данных

Через форму обратной связи собираются только следующие данные:

  • Имя — используется исключительно для вежливого обращения к пользователю в ответе;
  • Адрес электронной почты — используется исключительно для направления ответа на вопрос пользователя.

Оператор не собирает через данную форму номера телефонов, адреса доставки, файлы cookie и иные данные, не являющиеся необходимыми для указанной цели.

4. Срок обработки и хранения данных

Персональные данные обрабатываются в течение времени, необходимого для подготовки и отправки ответа пользователю. По завершении переписки данные удаляются и далее не хранятся и не используются.

5. Конфиденциальность и передача третьим лицам

Оператор обеспечивает конфиденциальность полученных данных. Персональные данные:

  • хранятся на сервере, расположенном на территории Российской Федерации;
  • не передаются третьим лицам;
  • не используются для рекламных, спам- или иных массовых рассылок.

6. Права пользователя

Пользователь вправе в любой момент:

  • запросить информацию о том, какие его данные обрабатываются;
  • потребовать уточнения, исправления или удаления своих персональных данных;
  • отозвать согласие на обработку данных.

Для реализации указанных прав пользователю необходимо направить запрос на адрес электронной почты, указанный в разделе «Реквизиты».
