## smn.png

"S", "M", "N" extracted from a hand-painted brush alphabet (Freepik asset
"handpaintedletters.zip", credited to Veraholera / Freepik), composited
into a single baseline-aligned wordmark and exported as a black-ink alpha
mask. Used as `mask-image` across `.wordmark`, `.hero-wordmark`, and
`.preloader-mark` in `css/style.css` — recolored per placement (solid
glossy black in the hero, the Sunset Spiral acid-gradient in the header).

This is a licensed third-party asset. If it was downloaded under a Freepik
**free** account, the license requires visible attribution on the site
(a link to freepik.com credited to Veraholera) — that has not been added
yet. If downloaded under a **premium** account, no attribution is
required. Confirm which applies before this goes fully public.
